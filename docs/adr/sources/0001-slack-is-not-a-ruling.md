# ADR 0001: Slack is not a ruling
Date: 2026-10-21

## Status

Accepted

## Context

42S-4 collected camagru threads from the school Slack. A first summary reversed the language history and called people staff who were not. The correction, quoted from the messages: before March 2021 the subject was PHP-based, and on 1 Mar 2021, 17:18, in `#42belgium_global_announcements`, the line is "camagru: language free." The 29 Jun 2022 Paris note was about API keys. Tailwind for camagru was asked about on 20 Nov 2025 and has no reply, and the peer notes about PDO, ORMs, and frameworks were not labeled staff. This ADR was written when the repo first had files.

## Decision

I will treat a Slack message as a ruling only when the message itself says so, and I will record its date, channel, and exact line. Peer notes stay peer notes, and the subject PDF outranks them.

## Consequences

The README and the defense cite the PDF, not a Slack summary. An unanswered question, including Tailwind, stays open. A later message that states a staff ruling gets its own ADR if it changes what I build.
